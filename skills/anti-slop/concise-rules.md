# Anti-Slop Design Rules (Active)

You are generating with Anti-Slop mode ON. Follow these rules strictly:

## HARD GATES (Never Break These)

1. **No decoration without purpose** — Every visual element must solve a problem. No gradient blobs, no floating shapes, no decorative dots.
2. **No AI-typical patterns** — No "Empower your...", no "Seamless...", no "Revolutionize...", no "Unlock the power of...". Write like a human.
3. **No fake metrics** — Never invent stats, percentages, or numbers. If you don't know, say so.
4. **No generic icons** — Use specific icons that match the content. No random sparkles or stars.
5. **No placeholder content** — Real copy, real data, real examples. No "Lorem ipsum" or "John Doe".

## LIVELINESS

6. **Vary sentence rhythm** — Mix short and long sentences. No uniform paragraph structure.
7. **Use concrete language** — "Users click the button" not "The button is clicked by users".
8. **Break symmetry intentionally** — Not everything needs to be centered or perfectly aligned.
9. **Show, don't tell** — Instead of "Our AI is powerful", show it doing something impressive.
10. **Add specific details** — "Built for 10,000+ teams" not "Built for teams everywhere".

## CODE

11. **No generic comments** — Delete "// Import React", "// Main component", "// Style the button". Keep only comments that explain WHY.
12. **No console.log in production** — Remove all debug logging.
13. **No TODO placeholders** — Implement it or remove it.

## COPY

14. **Active voice** — "We built this" not "This was built by us".
15. **Specific benefits** — "Saves 2 hours/week" not "Saves time".
16. **No buzzwords** — Avoid: leverage, utilize, streamline, empower, revolutionize, cutting-edge, game-changing.
17. **End with action** — Every section should lead somewhere. Don't leave the reader hanging.

## DELIVERY CHECK

Before delivering, verify:
- [ ] No decorative elements without purpose?
- [ ] No generic AI language?
- [ ] No fake statistics?
- [ ] Sentences vary in length?
- [ ] Copy is specific and concrete?
